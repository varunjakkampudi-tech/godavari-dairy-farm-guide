# User guide

## Start safely

1. Read [Start & feasibility](pages/getting-started.html) and the printable [farm launch workbook](pages/launch-workbook.html).
2. Confirm an eligible buyer, written lease permissions, reliable water/drainage, relief labor and veterinary access before paying an animal or construction advance.
3. Use the [finance studio](pages/finance-studio.html) with individual animal observations, real settlement slips and dated costs. Default or hypothetical values are not local quotes; its constant-yield calendar is a planning model, not an investment-grade forecast.
4. Read the buying and health pages; have a veterinarian independently inspect each animal.

## Find information

Use the search box in the shared navigation to search the current guide corpus. Browse individual pages for feeding, milking, seasons, breeding/calves, market, legal, emergency, staff and local verification. Sources and limitations are linked from guide pages. The red Emergency link on each page opens a symptom safety aid; select every observed sign, follow its escalation guidance, and contact a veterinarian. The tool does not diagnose or prescribe and has not received local veterinary review.

## Install and use offline

Open the site while online in a browser that supports web app installation. When the browser offers installation, use the **Install app** button in the header. The service worker caches the listed guide shell and local scripts; pages opened online can also be stored for later use. If a page is unavailable offline, use the offline screen to reach home, the finance studio, records or emergency guidance. Check the pages you need while online before entering a location with no connection. Farm records remain on the same browser profile and are not uploaded when connectivity returns.

## Compare milk settlement terms

Enter the same delivered quantity for both offers, then input only rates/quality/deductions shown by the buyer. A price per kg requires a density value supplied or measured for the actual milk; price per kg fat also requires the tested fat percentage. Do not treat examples or a calculated comparison as a verified buyer quote.

## Farm records

Animal, milk, expense and activity-log entries are kept in the current browser profile. Use the activity ledger for purchases, feed, health observations, vaccinations, milk withdrawal dates supplied by a vet/label, breeding, calves, labor, tasks, inventory, equipment, cleaning, weather, incidents, income and utilities. It records user entries; it does not diagnose or calculate medicine withdrawal periods. Search the registers, and filter farm logs by module and date. Use Edit to update a row and Delete for confirmed removal. Export JSON backups regularly and keep copies outside the device. CSV is for spreadsheets, not a backup restore. Version-1 records are migrated while retaining a recovery copy. Imported backups replace local rows only after confirmation. Do not put private banking or highly sensitive personal data in the app.

## Veterinary and legal limits

Use health content to notice changes and communicate with a veterinarian. It cannot diagnose or authorize treatment. Confirm vaccine timing and withdrawal periods with the veterinarian. Confirm licensing and labor/building rules for the actual business and parcel with the relevant authority or qualified adviser.
