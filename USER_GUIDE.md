# User guide

## Start safely

1. Read [Start & feasibility](pages/getting-started.html) and the printable [farm launch workbook](pages/launch-workbook.html).
2. Confirm an eligible buyer, written lease permissions, reliable water/drainage, relief labor and veterinary access before paying an animal or construction advance.
3. Use the calculator with real settlement slips and dated costs. Zero/default values are not quotes; the current model does not include all cash-flow risks.
4. Read the buying and health pages; have a veterinarian independently inspect each animal.

## Find information

Use the search box in the shared navigation to search the current guide corpus. Browse individual pages for feeding, milking, seasons, breeding/calves, market, legal, emergency, staff and local verification. Sources and limitations are linked from guide pages.

## Compare milk settlement terms

The new buyer comparison form is still local work in progress. Enter the same delivered quantity for both offers, then input only rates/quality/deductions shown by the buyer. A price per kg requires a density value supplied or measured for the actual milk; price per kg fat also requires the tested fat percentage. Do not treat examples or a calculated comparison as a verified buyer quote.

## Farm records

Animal, milk and expense entries are kept in the current browser profile. Export JSON backups regularly and keep copies outside the device. CSV is for spreadsheets, not a backup restore. Imported backups replace local rows only after confirmation. Do not put private banking or highly sensitive personal data in the app.

## Veterinary and legal limits

Use health content to notice changes and communicate with a veterinarian. It cannot diagnose or authorize treatment. Confirm vaccine timing and withdrawal periods with the veterinarian. Confirm licensing and labor/building rules for the actual business and parcel with the relevant authority or qualified adviser.
